# TBR 算法跨被试验证结果

## 方法

- 数据集条件：`EC` 代表闭眼静息，`ERP-num` 代表数字工作记忆任务。
- 匹配被试：两个条件均有 EDF 文件的 98 名被试（数字任务缺少 13、37 号）。
- 公平截取：每个条件均使用从记录第 10 秒开始的 60 秒数据。
- 通道：19 导 EEG，采样率 250 Hz。
- 预处理：50 Hz 陷波，随后 4–30 Hz 四阶 Butterworth 零相位带通。
- 功率谱：SciPy `periodogram`，2 秒窗、0.5 秒步长，每段得到 117 个窗口。
- TBR：每个窗口跨 19 个通道及频率点求均值，`TBR = mean(PSD[4:8 Hz]) / mean(PSD[13:30 Hz])`。
- 平滑：EWMA，`S[t] = 0.3*TBR[t] + 0.7*S[t-1]`。

## 实际运行结果

- 闭眼静息阶段群体平均 TBR：**16.0934**
- 数字工作记忆阶段群体平均 TBR：**13.0147**
- 平均差值（闭眼静息 − 数字任务）：**3.0786**
- 数字任务相对下降：**19.13%**
- 方向一致的被试：**65/98**（数字任务 TBR 低于其本人的闭眼静息 TBR）
- 配对样本 t 检验：**t = 3.4742，p = 0.000767**

数字工作记忆阶段的群体平均 TBR 明显低于闭眼静息阶段，符合预先给定的算法验收标准。个别被试方向相反是跨被试 EEG 差异、伪迹和固定 60 秒取段的正常现象，不应删除或人为调整。
