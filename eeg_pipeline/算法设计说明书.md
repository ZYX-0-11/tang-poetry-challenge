# 脑电专注力实时闭环系统 — 算法设计说明书

## 1. 系统架构

```
脑电头环 ──→ device_adapter.py ──→ bci_core.py ──→ live_server.py ──→ 前端网页
  (硬件)       (翻译成数组)          (TBR黑盒)        (WebSocket广播)    (能量条)
```

三个 Python 文件职责分明，更换硬件协议时只需修改 `device_adapter.py`，其余文件完全不动。

---

## 2. device_adapter.py — 硬件翻译器

**职责**：把不同协议的脑电数据流统一翻译成 `(channels, samples)` 格式的 numpy 数组。

**接口**：
```python
from device_adapter import open_source

source = open_source({'protocol': 'lsl'})  # 或 'serial' / 'udp' / 'mock'
chunk = source.read_chunk()  # → np.ndarray, shape=(19, 250), dtype=float64
source.fs                     # → 250.0 (采样率 Hz)
```

**已实现协议**：
| 协议 | 类名 | 状态 |
|---|---|---|
| mock | MockEDFSource | 可用（从 EDF 文件模拟实时流，用于离线测试） |
| lsl | LSLSource | 骨架已建，待硬件到货后补齐 `pylsl` 调用 |
| serial | SerialSource | 骨架已建，待补齐 `pyserial` 调用 |
| udp | UDPSource | 骨架已建，待补齐 `socket` 调用 |

## 3. bci_core.py — 核心黑盒

**职责**：喂进原始 EEG 数组，吐出 TBR 值和专注/走神状态。数据来源无关，纯数学计算。

**接口**：
```python
from bci_core import process, calibrate

# 第一步：30秒闭眼静息校准（只需做一次）
threshold = calibrate(resting_eeg, fs=250.0)

# 第二步：此后持续调用，每秒一次
result = process(eeg_chunk, fs=250.0, tbr_threshold=threshold)
result.state          # np.array, 0=走神 1=专注
result.smoothed_tbr   # np.array, 平滑后的 TBR 值
```

### 3.1 处理管线（七步）

| 步骤 | 方法 | 参数 | 说明 |
|---|---|---|---|
| 1. 坏通道剔除 | MAD 方差异常检测 | `mad_factor=5.0` | 方差超出中位数 ±5×MAD 的通道标记为坏，用相邻两通道均值替换 |
| 2. 工频陷波 | IIR Notch | 50 Hz, Q=30 | 去除 50Hz 市电干扰，零相位滤波 |
| 3. 带通滤波 | 4阶 Butterworth | 4–30 Hz | 零相位 (`sosfiltfilt`)，剔除 DC 漂移和高频肌电 |
| 4. 滑窗周期图 | SciPy `periodogram` | 窗长 2.0s，步长 0.5s | Hann 窗，去直流，功率谱密度 |
| 5. TBR 提取 | θ(4–8 Hz) / β(13–30 Hz) | — | 跨 19 通道和频点取均值，得一维 TBR 时间序列 |
| 6. 伪迹剔除 | 峰峰值异常检测 | `ptp_factor=3.0` | 窗内最大峰峰值超过所有窗中位数 3× 则标记为伪迹，线性插值填补 |
| 7. EWMA 平滑 | 指数加权移动平均 | `α=0.3` | `S[t] = 0.3×TBR[t] + 0.7×S[t-1]` |

### 3.2 个性化校准

- 方法：被试闭眼静息 30 秒，取此期间 TBR 中位数作为个人阈值
- 原理：TBR > 个人静息基线 → 比静息更"散" → 走神；TBR ≤ 基线 → 比静息更"紧" → 专注
- 基于 98 人伊朗数据集的群体默认阈值 14.0 仅作为后备

### 3.3 抗干扰设计

| 干扰源 | 防护机制 |
|---|---|
| 电极脱落/接触不良 | 坏通道 MAD 检测 + 邻居插值 |
| 50Hz 市电 | IIR 陷波器 |
| 眨眼（δ 波段大尖峰） | 4Hz 高通衰减 + 逐窗峰峰值异常检测 |
| 肌肉活动（>30Hz 高频） | 30Hz 低通滤波 |
| 轻微晃动（瞬态伪迹） | 逐窗峰峰值检测 → 插值填补 |
| 个体基线差异 | 30s 静息校准 → 一人一阈值 |

## 4. live_server.py — 实时推送器

**职责**：串联全流程，每秒通过 WebSocket 向前端网页广播当前状态。

**接口**（JSON over WebSocket）：
```json
{"state": 0, "tbr": 20.73}
{"state": 1, "tbr": 12.34}
```
- `state`: 0=走神, 1=专注
- `tbr`: Theta/Beta 比值

### 4.1 运行流程

1. 打开 EEG 数据源 (`device_adapter.open_source`)
2. 采集 30 秒静息数据，调用 `bci_core.calibrate()` 计算个人阈值
3. 启动 WebSocket 服务器 (`ws://localhost:9999`)
4. 主循环（每秒）：
   - `source.read_chunk()` → 采一帧
   - 追加到滑动缓冲区（最大 10 秒）
   - `bci_core.process()` → 算 TBR + 状态
   - 广播 JSON 到所有已连接的前端客户端

### 4.2 命令行参数

```
python live_server.py --help

  --protocol mock|lsl|serial|udp   数据源协议（默认 mock）
  --calibrate-sec 30               校准阶段时长（秒）
  --no-calibrate                   跳过校准，用群体默认阈值
  --port 9999                      WebSocket 端口
  --host localhost                 监听地址
  --chunk-seconds 1.0              每帧秒数
```

## 5. 前端对接

前端 (`index.html` + `api_receiver.js`) 已内置 WebSocket 客户端：

- 连接 `ws://localhost:9999`
- 收到 `{"state":0/1, "tbr":float}` 后：
  - 能量条：RGB 渐变（低分=红 → 高分=蓝）
  - 状态徽章：绿底"专注" / 红底"涣散"
  - 走神时答题区背景变暗
  - `calcFocusScore() = eegRatio×60 + perfScore×40 + focusAccumAdj`
- WebSocket 断开时自动回退到行为判定模式

## 6. 关键参数汇总

| 参数 | 值 | 说明 |
|---|---|---|
| 采样率 | 250 Hz | 伊朗数据集，实际设备可能不同 |
| 通道数 | 19 (伊朗) / 8 (头环待定) | 自动适配 |
| 窗长 | 2.0 s | FFT 分析窗 |
| 步长 | 0.5 s | 窗滑动步长 |
| θ 频段 | 4–8 Hz | Theta 波段 |
| β 频段 | 13–30 Hz | Beta 波段 |
| 陷波频率 | 50 Hz | 工频干扰 |
| 带通 | 4–30 Hz | 4阶 Butterworth 零相位 |
| EWMA α | 0.3 | 平滑强度 |
| 坏通道 MAD 因子 | 5.0 | 方差异常判定界 |
| 伪迹 PTP 因子 | 3.0 | 峰峰值异常判定界 |
| 默认 TBR 阈值 | 14.0 | 群体统计后备值 |
| WebSocket 端口 | 9999 | 前端连接地址 |
| 推送频率 | 1 Hz | 每秒一条 JSON |
