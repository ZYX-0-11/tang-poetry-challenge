# 脑电专注力实时闭环系统 — 操作手册

## 前置条件

- Linux 系统（Ubuntu 20.04+ 或同等）
- Python 3.10+
- 脑电头环已通过 USB/蓝牙连接到电脑

---

## 第一步：安装依赖

打开终端，进入 `eeg_pipeline/` 目录，安装 Python 依赖：

```bash
cd eeg_pipeline
pip install numpy scipy websockets
```

如果脑电头环走 LSL 协议，额外安装：
```bash
pip install pylsl
```

如果走串口/蓝牙，额外安装：
```bash
pip install pyserial
```

---

## 第二步：配置设备协议

编辑 `device_adapter.py`，找到文件末尾的 `open_source()` 函数（约第 180 行附近）：

```python
def open_source(config: dict | None = None) -> EEGSource:
    if config is None:
        config = {}

    protocol = config.get("protocol", "mock")
    #                        ^^^^^^
    #                        把 "mock" 改成 "lsl" 或 "serial"
```

同时在对应的 `XXXSource` 类中补齐硬件读写代码。

**如果只是想先测试管线是否跑通（不需要真实头环），可以跳过此步骤，直接用 mock 模式。**

---

## 第三步：启动后端服务

```bash
cd eeg_pipeline

# 方式A：mock模式（用数据集文件模拟脑电，测试管线）
python live_server.py --protocol mock --edf "EC/1 - rsEC.edf"

# 方式B：真实头环 LSL 模式（30秒闭眼校准后进入主循环）
python live_server.py --protocol lsl --calibrate-sec 30

# 方式C：真实头环 串口模式
python live_server.py --protocol serial --com-port /dev/ttyUSB0 --calibrate-sec 30
```

启动后终端会显示：
```
[live_server] 打开数据源: protocol=lsl
[live_server] 采样率=250.0 Hz  通道数=19
[live_server] 开始校准：闭眼静息 30.0s，采集 30 帧...
  校准进度: 30/30 帧
[live_server] 校准完成。个性化阈值=22.92 (群体默认=14.0)
[live_server] WebSocket: ws://localhost:9999
[live_server] 主循环运行中，等待前端连接...
```

**看到 "主循环运行中" 即表示后端正常，保持此终端不要关闭。**

---

## 第四步：打开前端网页

**在启动后端、看到 "主循环运行中" 之后**，打开浏览器访问：

```
https://zyx-0-11.github.io/tang-poetry-challenge/
```

网页加载后，前端会自动连接 `ws://localhost:9999`。

---

## 第五步：确认连接成功

观察网页上的能量槽区域：

- 左上角标签显示 **"硬件 EEG"** → 连接成功，能量条由真实脑电驱动
- 左上角标签显示 **"行为判定"** → 未连接到后端，使用了离线模拟模式

连接成功后：
- 能量条会随专注力实时变化（低=红色 ←→ 高=蓝色）
- 状态徽章显示 "专注"（绿底）或 "涣散"（红底）
- 走神时答题区背景会变暗

---

## 第六步：开始答题

1. 点击 "开始" 进入答题
2. 每题将 5 个字拖入正确顺序
3. 能量条实时反映脑电专注状态
4. 答完 20 题后展示六维能力雷达图

---

## 完整操作时序

```
步骤1 ── 安装依赖          （首次，1分钟）
步骤2 ── 配置协议          （首次，改一行代码）
步骤3 ── python live_server.py  （每次启动，先30s校准）
         │
         ├─ 0-30s:  闭眼静息校准（屏幕提示被试闭眼）
         ├─ 30s+:   校准完成，进入主循环
         │
步骤4 ── 浏览器打开网页     （主循环运行后打开）
步骤5 ── 确认 "硬件EEG" 标签 （1秒内自动连接）
步骤6 ── 开始答题           （能量条实时跳动）
```

## 常见问题

**Q: 网页显示 "行为判定" 而不是 "硬件 EEG"？**
A: 检查 live_server.py 是否正在运行，终端应显示 `主循环运行中`。确认防火墙没有阻止 9999 端口。

**Q: 校准阶段被试需要做什么？**
A: 闭眼、放松、不要刻意思考。保持头部稳定 30 秒。

**Q: 想用另一台电脑的浏览器看？**
A: 将 live_server.py 的 `--host` 改为 `0.0.0.0`，然后把 `index.html` 中 `ws://localhost:9999` 改为 `ws://<服务器IP>:9999`。

**Q: 不想校准怎么办？**
A: 加 `--no-calibrate` 参数，系统会使用群体默认阈值 14.0（精度会降低）。
